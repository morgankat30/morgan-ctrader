Connect cTrader Open API

This connects to your real cTrader Open API application and a real trading account (demo or live). Nothing is sent to any third-party wallet — only to cTrader's own servers.

You selected LIVE. This will authorize against your real cTrader account. Trades will only be sent if you separately arm live execution on the dashboard — connecting alone does not place any trade.

Don't have a Client ID/Secret/Access Token yet? See the setup steps at the bottom of this page.

Setup steps

1. Register a broker account that supports cTrader (link provided separately).
2. Go to openapi.ctrader.com/apps and log in with your cTrader ID.
3. Create a new application (any name/description) and wait for approval.
4. Open the app's Playground button — pick "trading" scope — and click "Get token". This gives you an Access Token + Refresh Token for your own account without building OAuth screens.
5. Paste the Client ID, Client Secret and Access Token above. Start on Demo.
