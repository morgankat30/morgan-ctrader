  1. Go to openapi.ctrader.com, sign in, register a new application (any name).
  2. Copy its Client ID/Client Secret into the fields above.
  3. Add this exact Redirect URI in that app's settings:
  4. Tap LOG IN WITH CTRADER above and approve access.
  5. Run the Termux command it gives you, paste the accessToken back into the field above, turn on Remember, tap CONNECT.
