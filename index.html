Setup steps

1. Register a broker account that supports cTrader (link provided separately).
2. Go to openapi.ctrader.com/apps and log in with your cTrader ID.
3. Create a new application (any name/description) — this works even while status shows "Submitted".
4. Copy its Client ID and Client Secret into the fields above.
5. Tap Log in with cTrader to get a token below — that's a real login/authorize screen, separate from the Sandbox tool, and it works without waiting for approval.
6. After you approve, you'll land back here with a token filled in automatically. Tap Connect. Start on Demo.

Setup steps

1. Open testnet.binance.vision, log in with GitHub, generate an HMAC API key — instant, no approval, use this to try everything risk-free first.
2. For real trading later: on the real Binance app/site go to Profile → API Management → Create API, enable the required Spot and/or Futures trading permission only (leave withdrawals off), and restrict it if you can. Binance requires standard account KYC for live trading, separate from this API step.
3. Paste the API Key and Secret above.
4. Download binance_relay.py (link provided separately), run python3 binance_relay.py in Termux in this project's folder, and open this page through http://localhost:8788/index.html (not the https GitHub link) whenever you want real orders to actually go through — the relay only works when the page and script are on the same device.
5. Tap Connect. Start on Testnet.
