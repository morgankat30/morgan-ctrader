cTrader Connect

This connects to your real cTrader Open API application and a real trading account (demo or live). Nothing is sent to any third-party server — only to cTrader's own servers, straight from this page.

Remember loginSaves these fields in this browser so you don't retype them. Anyone with access to this phone/browser could see them.

Needs Client ID filled in above first. Opens cTrader's real login page; after you approve, it sends you back here with a one-time code — you'll then run a short command in Termux to turn that into your Access Token (browsers can't complete that last step directly).

Need the Client ID/Secret first? See the setup steps below.

Setup steps
  1. Go to openapi.ctrader.com, sign in, and register a new application (any name).
  2. Copy the Client ID and Client Secret it gives you into the fields above.
  3. In that application's settings, add this exact URL as an allowed Redirect URI:
  4. Come back here and tap LOG IN WITH CTRADER TO GET A TOKEN — approve access to your demo or live account.
  5. You'll land back here with a ready-made command — copy it, run it in Termux, then paste the accessToken value from the reply into the Access Token field above. Turn on Remember, then tap CONNECT.
